# Kechuang Scenario Catalog

本清单只考虑正常业务与正常环境演化，暂不引入设备故障、传感器掉线、会议取消或
人工覆盖。优先级考虑现有工具复用程度、对物理引擎的覆盖和对 Agent 决策能力的检验。

## K1324：研究生办公室

| 优先级 | 场景 | 核心过程 | 主要检验点 |
|---|---|---|---|
| 已实现 | 工作日人数阶梯 | 师生分批到达、工作、离开、空房通风 | 17 人容量、占用事件、CO₂ 演化与恢复 |
| 已实现 | 办公环境协调 | 制冷、加湿、分阶段复测、低档维持 | 命令与物理结果分离、温湿度反馈 |
| P1 | 固定工位与人员定位 | 教师进入独立办公室、学生进入固定工位 | 功能分区、人员位置、房间总人数一致性 |
| P1 | 工作日节能运行 | 上班前预处理、有人维持、午间降档、下班关闭 | 时间表、舒适度、累计能耗 |
| P2 | 分区舒适度观测 | 教师隔间与开放工位增加真实测点后比较 | 功能区到物理 zone 的升级边界 |

K1324 不参与会议室预约。涉及讨论或正式会议的请求必须转向 K1316 或 K1315。

## K1316：研讨室

| 优先级 | 场景 | 核心过程 | 主要检验点 |
|---|---|---|---|
| 已实现 | 小型研讨完整流程 | 预约、会前通风、投影/照明准备、8 人研讨、关机 | 容量、设备 readiness、CO₂、资源释放 |
| P1 | 混合研讨准备 | 投影与视频研讨能力检查、环境预处理 | capability 选择、工具顺序、会前核验 |
| P1 | 连续两场研讨周转 | 第一场结束、短时换场通风、第二场开始 | 相邻日程、资源状态、环境继承 |
| P2 | 小组讨论模式 | 低人数、较低照明和通风档位 | 小房间控制策略与能耗效率 |

K1316 已有房间专属设备与物理时间线覆盖；下一项优先考虑连续两场研讨周转。

## K1315：会议室

| 优先级 | 场景 | 核心过程 | 主要检验点 |
|---|---|---|---|
| 已实现 | 标准正式会议 | 打印、通风、制冷、净化、灯光、投影音响、完整关机 | 长工具链、设备热负荷、会议生命周期 |
| P1 | 汇报答辩会议 | 演示区与观众区不同灯光、打印评审材料、麦克风准备 | 多设备协同、功能分区、材料任务 |
| P1 | 长时委员会会议 | 周期环境检查并动态调整通风/HVAC | 长时反馈控制、CO₂ 与能耗平衡 |
| P2 | 多阶段会议 | 准备、报告、讨论、休息、恢复会议、结束 | 阶段事件、不同设备场景切换 |

## 跨房间场景

| 优先级 | 场景 | 核心过程 | 主要检验点 |
|---|---|---|---|
| 已实现 | 冲突后的房间选择 | K1315 冲突，选择满足 6 人投影需求的 K1316 | 可预约性、容量、能力和冲突规则 |
| P1 | 按人数和设备自动选房 | 小组研讨选 K1316，正式会议选 K1315 | 多约束决策，不可预约办公室过滤 |
| P1 | 同时段双会议协调 | K1315 与 K1316 同时运行不同规模会议 | 多 zone 物理推进、设备隔离、总能耗 |
| P2 | 办公室到会议室联动 | 从 K1324 人员日程触发会议室准备 | 人员位置、预约、准备事件的跨房间因果链 |

## 推荐实现顺序

1. 跨房间按人数和设备自动选房；
2. K1324 工作日节能运行；
3. K1315 长时委员会会议；
4. K1316 连续两场研讨周转；
5. 同时段双会议协调。
